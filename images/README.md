## Replacing Images

To replace any image:
1. Visit Unsplash.com or Pexels.com
2. Search for your desired image
3. Copy the image URL
4. Replace the URL in the HTML file
5. Adjust sizing parameters in the URL (?w=width&q=quality)

## Image Optimization Tips

- Use appropriate width parameters (?w=800, ?w=1200, ?w=1920)
- Set quality parameter for balance (?q=80 is recommended)
- Consider using WebP format for better compression
- Add lazy loading for images below the fold
