HOW TO REPLACE IMAGES:
-----------------------

1. Visit Unsplash.com
2. Search for your desired image type (e.g., "real estate", "office", "business")
3. Click on an image
4. Click "Share" or copy the direct image URL
5. Replace the URL in the HTML file
6. Add parameters for sizing:
   - ?w=1920 (for hero images)
   - ?w=800 (for content images)
   - ?w=400 (for team photos)
   - &q=80 (for quality, 80% is recommended)

Example: https://images.unsplash.com/photo-XXXXXX?w=1920&q=80
