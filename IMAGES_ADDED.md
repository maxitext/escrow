## 🔄 Want to Change an Image?

### Easy 3-Step Process:

1. **Visit Unsplash.com**
   - Search for your desired image type (e.g., "modern office", "real estate")

2. **Get the Image URL**
   - Click on the image you like
   - Right-click and "Copy Image Address"
   - Or use the Share > Copy Link feature

3. **Replace in Your HTML**
   - Find the old image URL in your HTML file
   - Replace with your new URL
   - Add sizing parameters: `?w=1920&q=80`

### Example:
```html
<!-- Old -->
style="background-image: url('https://images.unsplash.com/photo-OLD-ID?w=1920&q=80');"

<!-- New -->
style="background-image: url('https://images.unsplash.com/photo-NEW-ID?w=1920&q=80');"
```

## 📦 Alternative Options

### Download and Host Locally:
If you prefer to host images yourself:

1. Download images from Unsplash
2. Create an `/images` folder in your project
3. Save images there (e.g., `hero-bg.jpg`, `team-member-1.jpg`)
4. Update HTML to use relative paths:
   ```html
   style="background-image: url('images/hero-bg.jpg');"
   ```

## 🎯 Image Sizing Guide

For best performance, use these width parameters:

| Image Type | Recommended Width | URL Parameter |
|------------|------------------|---------------|
| Hero backgrounds | 1920px | `?w=1920&q=80` |
| Content images | 800px | `?w=800&q=80` |
| Team photos | 400px | `?w=400&q=80` |
| Thumbnails | 300px | `?w=300&q=80` |
